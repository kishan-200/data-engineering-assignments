# Day 10 – Power BI Engineering Capstone

## Overview

This project implements a Power BI engineering workflow covering data ingestion, Power Query ETL, dimensional modeling, DAX measures, and interactive business intelligence dashboards.

## Key Components

- Multi-source data ingestion
- Power Query transformations
- Star schema data model
- Date dimension
- DAX measures and KPIs
- Executive Overview dashboard
- Sales Analysis dashboard
- Customer 360 dashboard

## Tools Used

- Power BI Desktop
- Power Query
- DAX
- CSV / Excel data
- MySQL
